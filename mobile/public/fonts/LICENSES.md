# Bundled fonts

All fonts here are self-hosted so the app never fetches from a CDN (offline-first).
Each is distributed by Google Fonts under the SIL Open Font License 1.1
(https://openfontlicense.org), which allows bundling in apps.

| Family             | Files                         | Use                                  |
| ------------------ | ----------------------------- | ------------------------------------ |
| Cormorant Garamond | `cormorant-garamond-*.woff2`  | Display headings (Design Lock v1.0)  |
| Nunito Sans        | `nunito-sans-*.woff2`         | Interface text (Design Lock v1.0)    |
| Tajawal            | `tajawal-*.woff2`             | Arabic interface text                |
| Amiri Quran        | `amiri-quran-*.woff2`         | Qur'an text (unchanged)              |
| Amiri              | `amiri-*.woff2`               | Arabic names and words (unchanged)   |

Cormorant Garamond and Nunito Sans are variable fonts: one file covers weights 400-700.
